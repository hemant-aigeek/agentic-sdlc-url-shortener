# Human Approval Records

Every mandatory human gate in this repository has a record here. A record is
written **after** the decision is made, by the human candidate, and states what
was reviewed, the decision, and any conditions. Agents never write to this
directory.

Format: `GATE-<n>-<slug>.md`, one file per gate decision. Re-decisions append a
new file rather than editing the old one.
